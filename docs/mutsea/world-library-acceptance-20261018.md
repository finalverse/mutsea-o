## Source inventory and rights

The acquisition run considered 31 catalog entries. Of 28 compatible-source URLs attempted, 13 passed bounded quarantine and native object deserialization (57,348 parts in total), while 15 were rejected for format, size or integrity. Two Aurora/WhiteCore entries and mixed-license OpenVCE were deferred. All outcomes and source pins are in [the acquisition manifest](../../deploy/library/acquisition-20261018.json).

Only the three dependency-complete imported scenes above are admitted to the live cloud. The remaining candidates stay in private staging; they are not advertised as playable worlds. OpenVCE remains held for contributor-specific license review, not mislabeled as CC0. Larger archives require explicit revised budgets and separate admission; download availability alone is insufficient.

A deterministic derivative remaps each publisher archive's colliding blank-texture UUID, preserving the texture bytes and creator attribution. Both upstream and derivative hashes are retained. Other UUID/content conflicts still fail closed; no force-assets override is used.

## Native and automated evidence

- Isolated native restore: three committed import receipts, correct counts and ownership; repeated restart preserves them. Both script engines remain disabled.
- Isolated ordinary-user lifecycle: discovery, all four region teleports and full object streams; Save release → publish free → remix preview → Apply → save child with parent lineage → unpublish → Undo both creations. Existing native execution, permission checks and journals remain authoritative.
- Logout regression: capabilities now revoke on native `OnLogout` and client closure, rebind on returning root agents, and require an active client that is not logging out. The isolated regression confirms acknowledgement plus immediate stale-capability rejection. The public dispatcher can return empty HTTP 200 after handler removal; this is not World API success. The probe checks payload as well as status and rejects a successful JSON result or unrecognized nonempty body.
- Public TLS/native UDP acceptance passes for all five directory destinations; each of the four new scenes reaches its audited base part count (plus the probe avatar attachment). The hosted read-only answer names Conversation Circle, Review Pavilion and Quiet Shore. Return, local transport closure and stale-capability unavailability pass. The final portable SDK run did not observe the optional UDP LogoutReply; that diagnostic is recorded separately rather than represented as a received acknowledgement. Loopback results alone do not establish public reachability.
- Preservation audit against the pre-deployment PostgreSQL snapshot: all six account records and 80 inventory items are byte-for-byte unchanged; Harbor retains all 423 part IDs/owners/permissions, all 423 shape records and its original parcel record.
- 61 World Kernel tests; 50 content tests; 27 OAR converter tests; eight acquisition tests; 16 library/creator tests; 14 planning-boundary checks; three native rekey checks. Studio's changed place/world suites pass ten tests.
- Gateway: 81 tests, one optional integration test skipped. Workspace context is bounded and allowlisted in both simulator and gateway; arbitrary fields and transcripts are excluded.
- Viewer: universal native build succeeds. 119 CTest entries pass: 118 unchanged tests using RelWithDebInfo binaries and the changed presentation suite using its rebuilt Release binary (12 cases). This is not a claim that every test target was rebuilt in Release.

## Native viewer gate

The universal Mac client displayed all five online destinations and entered Confluence. A subsequent teleport exposed source `DisableSimulator` arriving before destination movement completion, which the inherited viewer treats as a disconnect. A bounded MutSea-only handoff fix is being verified; ordinary shutdowns, system grids and timeout behavior must remain intact. **Do not infer a new installer release or complete native multi-region qualification from the portable protocol tour.** The existing preview.3 installer can encounter this race.

## Creator release scope

Immutable creator recipes, private ownership, explicit free CC0 publication, unpublication and parent-linked remixes are implemented. Save checks every committed placement fingerprint and owner; manual edits outside a recipe must be saved using native inventory rather than silently discarded. Priced offers are metadata only: **checkout, payment, payout and commercial entitlements are disabled**. There is no arbitrary public OAR upload, full-region marketplace publication or mixed-license asset laundering path.

## Confluence scope and next acceptance

Authenticated inspection supplies Confluence's actual zone names, purposes and bounded locations. The configured hosted model receives that context and returns a read-only answer or a proposal for human review. Nearby voice/chat, private transcripts and credentials are not captured. A spatial seat is not a private AI session or a tool grant.

The next implementation is an explicit workspace session: participant consent, private threads, bounded artifact references, cancelable agent turns and reviewed world proposals. It will reuse MutSea identity, native permissions and WorldLine. No arbitrary shell/Python execution is implied.

These imported samples and the original workspace are a functioning preview foundation. Premium art, decoded-texture visual inspection across all source scenes, collision/LOD coverage and multi-user/device/load qualification are separate gates. A successful native import is not a claim of legendary artwork, high frame rate or GA cloud readiness.
